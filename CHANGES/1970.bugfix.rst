Rejected an empty authority for the ``http``, ``https``, ``ws``, ``wss`` and
``ftp`` schemes in WHATWG mode, as the WHATWG URL Standard does:
``http://``, ``http:///`` and ``http://?q`` were accepted. A URL of these
schemes without an authority, such as ``http:?q``, is still a reference to
a base and is now printed without ``//``, as ``http:?q`` instead of
``http://?q``
-- by :user:`asvetlov`.
