Restored coverage measurement of the Cython modules in CI, which had reported
nothing since line tracing stopped being requested when translating the
sources -- and, on CPython 3.13 and later, because Cython routes tracing
through ``sys.monitoring``, which the ``Cython.Coverage`` plugin cannot
consume. Windows stays unmeasured: the defines ride on ``CFLAGS``, which
setuptools forwards only to the Unix compiler
-- by :user:`rodrigobnogueira`.
