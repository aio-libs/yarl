Fixed :meth:`URL.join() <yarl.URL.join>` returning the reference unchanged,
often as a relative URL, when the base URL uses a scheme that is not listed
in ``urllib.parse.uses_relative``, such as ``mailto:``, ``urn:``,
``data:`` or any custom scheme; references are now resolved against every
base as described in :rfc:`3986#section-5.2`
